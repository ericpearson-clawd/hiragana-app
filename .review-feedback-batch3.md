## ❌ CRITICAL BUG: getWeakCharacters() Line 184

**Location:** `src/utils/spacedRepetition.js:184`

**Issue:** Variable `total` is defined in `.filter()` scope but referenced in `.map()` scope.

```javascript
// BROKEN CODE:
.filter(([char, data]) => {
  const total = (data.correct || 0) + (data.incorrect || 0);  // Defined here
  // ...
})
.map(([char, data]) => ({
  accuracy: total > 0 ? (data.correct / total) * 100 : 0,  // ❌ UNDEFINED!
}))
```

**Fix:**
```javascript
.map(([char, data]) => {
  const total = (data.correct || 0) + (data.incorrect || 0);  // Calculate here
  return {
    char,
    srsLevel: data.srsLevel || 0,
    accuracy: total > 0 ? (data.correct / total) * 100 : 0,
    ...data,
  };
})
```

**Impact:** Runtime crash when user views weak characters section (ReferenceError: total is not defined).

**Test Result:**
