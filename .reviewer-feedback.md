## 🔧 REQUIRED FIXES (Must complete before commit)

### 1. Quiz Options Gap Inconsistency
**File:** `src/index.css`  
**Line:** `.quiz-options { gap: 1rem; }`

**Issue:** Desktop uses `1rem` instead of 8pt grid variable. Mobile correctly uses `var(--space-md)`.

**Fix:**
```css
.quiz-options {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: var(--space-md); /* Change from 1rem */
  max-width: 400px;
  margin: 0 auto;
}
```

---

### 2. Card Hint Contrast Failure
**File:** `src/index.css` (in Flashcards.jsx styles)  
**Line:** `.card-hint { color: var(--text-muted); }`

**Issue:** `--text-muted` (#94a3b8) on white background = 3.2:1 contrast ratio ❌ (fails WCAG AA 4.5:1 requirement)

**Fix:**
```css
.card-hint {
  position: absolute;
  bottom: var(--space-lg);
  font-size: var(--font-size-sm);
  color: var(--text-secondary); /* Change from --text-muted */
}
```
