## 🎯 Implemented Features

### 1. Spaced Repetition System (SRS)
**File:** `src/utils/spacedRepetition.js` (NEW)

- **8 SRS Levels** with progressive intervals:
  - Level 0: New (immediate)
  - Level 1: 4 hours (Apprentice I)
  - Level 2: 8 hours (Apprentice II)
  - Level 3: 1 day (Apprentice III)
  - Level 4: 3 days (Apprentice IV)
  - Level 5: 7 days (Guru I)
  - Level 6: 14 days (Guru II)
  - Level 7: 30 days (Master)
  - Level 8: 90 days (Enlightened)

- **Smart Level Progression**:
  - Correct answer → Move up one level
  - Incorrect answer → Drop to half level (minimum level 1)
  - Based on WaniKani's proven methodology

- **Visual Interval Display**: Each level shows time until next review
- **Color-Coded Levels**: Matches existing mastery color scheme
- **Utility Functions**:
  - `calculateNextReview()` - SRS algorithm
  - `getDueReviews()` - Get characters ready for review
  - `getReviewSchedule()` - Preview upcoming reviews
  - `formatTimeUntil()` - Human-readable time formatting
  - `getWeakCharacters()` - Identify struggling characters

### 2. Review Schedule Component

### 3. Weak Character Targeting
**File:** `src/components/WeakCharacters.jsx` (NEW)

- **Color-Coded Borders**: Border color matches SRS level

- **Quick Action Button**: "Practice Weak Characters" navigates to focused practice

## 🔧 Technical Details

### SRS Integration with useProgress
- Modified `recordAttempt()` to:
  1. Initialize character with `initializeSRS()` if new
  2. Calculate next review time using `calculateNextReview()`
  3. Store SRS level, next review timestamp, and level name
  4. Maintain backward compatibility with existing stats

### Data Structure
Each character now stores:
```javascript
{
  correct: 15,
  incorrect: 3,
  lastSeen: 1739025600000,
  lastReview: 1739025600000,
  srsLevel: 5,               // NEW
  nextReview: 1739630400000, // NEW
  levelName: "Guru I",       // NEW
  reviewCount: 18            // NEW
}
```

### Performance Optimizations
- `getDueReviews()` uses single pass filtering
- `getReviewSchedule()` computes all time buckets in one loop
- Components use React best practices (memoization where needed)
